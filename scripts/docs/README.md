# ساخت PDF مستندات فارسی

این پوشه، چهارده فایل مارک‌داون `docs/*.md` را به یک کتاب PDF سیصدونه صفحه‌ای
تبدیل می‌کند: `docs/project-documentation-fa.pdf`.

بیرون از این پوشه هیچ‌چیز را تغییر نمی‌دهد جز دو فایل خروجی در `docs/`.

---

## اجرا

```bash
npm run docs:pdf
```

همین یک دستور کل زنجیره را می‌برد: ساخت HTML ← بازرسی هندسی نمودارها ← رندر PDF.

اگر خواستید مرحله‌به‌مرحله جلو بروید:

| دستور | کار |
|---|---|
| `npm run docs:build` | فقط `docs/documentation.html` را می‌سازد |
| `npm run docs:check` | هندسهٔ برچسب‌های نمودارها را می‌سنجد |
| `npm run docs:render` | HTML را به PDF تبدیل می‌کند |
| `npm run docs:render -- 1,26,171` | PDF + عکس PNG از این صفحه‌ها |

عکس‌ها در `scripts/docs/.shots/` می‌نشینند (در `.gitignore` هست).
شمارهٔ صفحه‌ها **شمارهٔ PDF** است، یعنی جلد صفحهٔ ۱ — نه عددی که پای صفحه چاپ شده
(آن یکی همیشه یکی کمتر است، چون جلد شماره نمی‌خورد).

برای وارسی دقیق یک گوشه از یک صفحه:

```bash
# صفحهٔ ۲۶، از ۸٪ عرض و ۸٪ ارتفاع، به اندازهٔ ۹۰٪ در ۳۲٪، با بزرگ‌نمایی ۴
node scripts/docs/zoom.mjs 26 8 8 90 32 4 arch
```

### پیش‌نیازها

- `npm install` در **ریشهٔ** مخزن (نه داخل این پوشه). سه وابستگی لازم است و هر سه
  با نسخهٔ دقیق در `package.json` ریشه پین شده‌اند: `marked`، `playwright`،
  `pdfjs-dist`.
- یک مرورگر: اول سراغ **کروم نصب‌شدهٔ سیستم** می‌رود؛ اگر نبود، خودکار به
  کرومیوم خود Playwright برمی‌گردد. برای نصب دومی:
  `npx playwright install chromium`.
- به مونگو یا سرور پروژه **کاری ندارد**؛ فقط فایل‌های مارک‌داون را می‌خواند.

---

## فایل‌ها

| فایل | کار |
|---|---|
| `build.mjs` | مارک‌داون ← HTML. رنگ‌آمیزی کد، کال‌اوت‌ها، جدول‌ها، جلد، فهرست مطالب، و جاگذاری نمودارها. تنها فایلی که CSS کتاب را دارد. |
| `diagrams.mjs` | چهارده نمودار SVG دست‌نویس. هیچ وابستگی بیرونی ندارد و فقط یک شیء از توابع صادر می‌کند. |
| `paginator.js` | صفحه‌بند. **کد مرورگر است، نه ماژول نود** — با `readFileSync` خوانده و داخل HTML تزریق می‌شود. برای همین `.js` مانده و ESM نیست. |
| `render.mjs` | HTML ← PDF با Playwright، و رستر کردن صفحه‌های نمونه به PNG. |
| `check-svg.mjs` | بازرسی هندسی نمودارها با اندازه‌گیری واقعی `getBBox`. |
| `zoom.mjs` | بزرگ‌نمایی یک ناحیهٔ دلخواه از یک صفحهٔ PDF. |
| `fonts/` | وزیرمتن (سه وزن) و JetBrains Mono (دو وزن)، `.ttf`. |

## چند نکته که وقت‌گیر بودند

**فونت‌ها در مخزن‌اند و base64 داخل HTML می‌روند.** نه از گوگل‌فونت خوانده
می‌شوند نه از فونت سیستم. اگر فونت جای دیگری باشد، کرومیوم موقع چاپ با فونت
جانشین اندازه می‌گیرد و ته هر صفحه چند خط بیرون می‌زند. `paginator.js` هم
عمداً پیش از صفحه‌بندی منتظر `document.fonts.load` می‌ماند.

**صفحه‌بندی دست خودمان است، نه مرورگر.** متن در `#src` پنهان می‌شود و
`paginator.js` عنصربه‌عنصر داخل صفحه‌های `.pg` می‌ریزد و ارتفاع را اندازه
می‌گیرد؛ بلوک کد، جدول و فهرستِ بلندتر از یک صفحه را خودش می‌شکند و سرستون
جدول را تکرار می‌کند. برای همین شمارهٔ صفحه‌های فهرست مطالب دقیق درمی‌آید.
`render.mjs` با `preferCSSPageSize` و حاشیهٔ صفر چاپ می‌کند، چون حاشیه‌ها
همان `--mt/--mb/--mi` داخل CSS‌اند.

**نمودارها از روی امضای متنی جاگذاری می‌شوند.** `DIAGRAM_RULES` در `build.mjs`
یک تکه‌متن از هر بلوک کد اسکی‌آرت را می‌شناسد و آن بلوک را با SVG عوض می‌کند.
یعنی **اگر آن خط را در فایل مارک‌داون ویرایش کنید، نمودار بی‌صدا ناپدید
می‌شود** و به‌جایش همان اسکی‌آرت می‌ماند. تعداد نمودارها را خط آخر خروجی
`docs:build` چاپ می‌کند — باید ۱۴ باشد.

**راست‌به‌چپ، جایی که واقعاً گاز می‌گیرد.** سه تلهٔ بایدی که هر کدام یک بار
خروجی را خراب کردند و حالا در کد بسته شده‌اند:

- در SVG، `text-anchor` **منطقی** است نه دیداری: در متن راست‌به‌چپ `start`
  یعنی لبهٔ راست. تابع `txt()` این را برای متن فارسی جابه‌جا می‌کند.
- تکهٔ لاتین داخل برچسب فارسی، نشانه‌های چسبیده‌اش (`@`، `/`، پرانتز) را از
  متن دور خود می‌گیرد؛ `/api/…` می‌شود `…//api`. هر تکهٔ لاتین در
  `isolateLatin()` داخل جداساز `LRI…PDI` بسته می‌شود.
- بلوک کد با `unicode-bidi:plaintext` جهت **هر خط** را از اولین حرف همان خط
  می‌گیرد؛ خطی از یک کامنت فارسی که اتفاقاً با واژه‌ای لاتین شروع شود
  چپ‌به‌راست می‌شود و آن واژه به ته جمله پرت می‌شود. کامنت‌های فارسی حالا
  یک جزیرهٔ راست‌به‌چپ‌اند.

**`check-svg.mjs` را جدی بگیرید.** چیزی را پیدا می‌کند که چشم به‌سختی می‌بیند:
متنی که کادر `<rect>` بعدی رویش افتاده، «بریده» به نظر می‌رسد نه پوشیده. اگر
`CLIPPED` یا `OCCLUDED` صفر نباشد خروجی‌اش قرمز می‌شود و `docs:pdf` همان‌جا
می‌ایستد. `OVERLAPS` اما فقط گزارش است: سه موردِ فعلی، برچسب‌های عمداً
دوخطی‌اند که جعبه‌شان ۲-۳ نقطه تماس دارد.

**اسکی‌آرتِ فارسی‌دار در بلوک کد جواب نمی‌دهد.** ادامهٔ همان تلهٔ سوم بالا، ولی
جایی که خیلی راحت‌تر گاز می‌گیرد. رنگ‌آمیزِ `build.mjs` فقط **کامنت**‌های فارسی
(`//`, `/* */`, `#`) را در جزیرهٔ راست‌به‌چپ می‌بندد. متن فارسیِ آزاد داخل یک
نمودار اسکی هیچ جزیره‌ای ندارد، پس هر خطی که با کاراکتر خنثی (`│`, `├`, فاصله)
شروع شود و اولین حرفِ قویِ آن فارسی باشد، کلاً برعکس می‌شود و ستون‌های نمودار
از هم می‌پاشند. دو راه سالم: یا نمودار را تمام‌لاتین بنویسید و توضیح فارسی را
بیرونِ بلوک بیاورید، یا برایش یک SVG در `diagrams.mjs` بسازید و امضایش را به
`DIAGRAM_RULES` اضافه کنید.

**قالب‌بندی.** چهار فایل از این پوشه در `.prettierignore` هستند، چون مختصات
SVG و جدول رنگ‌ها دستی ستون‌به‌ستون هم‌تراز شده‌اند. `eslint` روی همه‌شان
اجرا می‌شود. اگر فایل تازه‌ای اینجا اضافه کردید، پیش‌فرض این است که prettier
قالبش را بزند — مگر آگاهانه استثنایش کنید.
